# ***The Spirits Connection: Discovering Liquor Pairing Trends***
>Market Basket Analysis using Association Rule Mining

📌 Overview

This project analyzes customer purchasing patterns in a liquor retail environment using Market Basket Analysis (MBA) and Association Rule Mining.
A small synthetic dataset containing liquor-related transactions (whisky, rum, vodka, wine, mixers, snacks, etc.) was prepared in multiple formats to support pattern discovery.

### Using the Apriori algorithm, the project uncovers:

* Frequently purchased liquor combinations

* Popular liquor–mixer pairings

* Cross-selling opportunities with snacks

* Hidden relationships useful for marketing and store optimization

### The insights help retailers:

* Improve product placement

* Create promotional combo offers

* Enhance customer experience with smart recommendations

* Support data-driven decision-making

## 🧹 Data Preparation

>To ensure accurate results, the dataset underwent multiple preprocessing steps:

* Data cleaning

* Standardizing transaction formats

* Grouping similar items

* Structuring data for Association Rule Mining

* Even with a small dataset, meaningful patterns emerged—showing that proper preprocessing boosts analysis quality.

## 🧠 Techniques Used

* Market Basket Analysis (MBA)

* Association Rule Mining

* Apriori Algorithm

* Frequent Itemset Mining

* Data Preprocessing & Transaction Formatting



### 🔍 Key Results

* Identified strong liquor–mixer combinations

* Found snack items frequently bought with specific drinks

* Insights useful for combo-offer creation and recommendation systems

* Demonstrated value of pattern mining even on small datasets
